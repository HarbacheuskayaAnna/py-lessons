# Py-lessons

My learning repository: Python basics for test automation.
I'm a manual QA engineer moving into automation (pytest, API and UI tests).

## Topics covered
- Functions, lists, dictionaries
- Strings, f-strings, list comprehensions
- Exceptions, modules, reading JSON files
- Classes (OOP basics)
- Virtual environment (venv), pip, requirements.txt
- First API requests with `requests`, a simple `ApiClient` class
- Git: init, commit, .gitignore, branches, pull requests

## How to run
```
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python <file_name>.py
```
